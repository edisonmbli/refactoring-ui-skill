# Worked examples

Three before → after cases, each showing the audit reasoning rather than only the
result. They serve two purposes:

1. **Few-shot material.** They demonstrate the shape of a good finding: a symptom,
   the rule it violates, the mechanism, and a specific change.
2. **Eval fixtures.** Each lists the findings a correct audit should surface, so
   the skill can be regression-tested as it changes.

Colors appear as `{primary}` / `{neutral}` / `{danger}` placeholders, per
`SKILL.md` → *Reading the reference files*.
