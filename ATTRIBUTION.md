# Attribution

## The source

Every design principle encoded in this skill originates in:

> **Refactoring UI** — Adam Wathan & Steve Schoger
> <https://www.refactoringui.com>

It is an excellent book. **Buy it.** This skill is not a substitute for reading it,
and is not intended to be one — it is a tool for applying principles you should
learn properly from the source.

## What this project is, and is not

**This is an unofficial, independent project.** It is not affiliated with, endorsed
by, sponsored by, or reviewed by Adam Wathan, Steve Schoger, or Tailwind Labs.

**What it contains:** design rules restated in our own words as executable
guidance, organized for machine consumption, mapped to Tailwind utilities, and
accompanied by scripts that implement the book's algorithms.

**What it deliberately does not contain:**

- No prose copied from the book.
- **None of the book's 284 figures or illustrations.** Where a figure carried
  information, we describe the relationship it demonstrates in our own words.
- No reproduction of the book's layout, structure as presented, or design.
- Nothing that would let a reader substitute this repository for the book. The
  references state rules; the book teaches you to see.

Copyright protects expression, not ideas, methods, or facts. This project takes
the methods and expresses them independently. We have been deliberately careful
about the line, because the book is a commercial product and its authors deserve
to sell it.

## Numeric values

Certain specific values appear here because they *are* the rules, and stating a
rule requires stating its threshold — 45–75 characters per line, 4.5:1 contrast,
a 16px-based spacing scale, a five-level elevation scale. Several of these are not
original to the book in the first place (WCAG contrast ratios, the classical
measure range). Others are the book's own recommendations, cited as such.

## Colors

**The book contains no specific color values.** Every palette shown in it is an
illustration. All colors this skill produces are generated by
`scripts/generate_palette.py` from the algorithm the book describes. Nothing was
sampled from the book's images.

## Tailwind CSS

Tailwind's default scales and this book's scales coincide because Adam Wathan
wrote both. Where this skill notes that identity, it is describing a documented
historical fact about the framework's origin, not claiming any relationship with
Tailwind Labs.
